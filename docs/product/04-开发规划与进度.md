# 04 · 开发规划与进度（V1）

> 本文档是 V1 的任务拆解与进度跟踪表，颗粒度到可独立验收的任务。状态标注约定：`未开始` / `进行中` / `已完成` / `阻塞`。架构背景见 [01-整体认知与上手指南](./01-整体认知与上手指南.md)，实现细节见 [02-架构实现与调用链路](./02-架构实现与调用链路.md)。

最后更新：2026-08-27（初始规划，全部任务未开始）

## 1. V1 范围边界

| 做（V1） | 不做（推迟） |
|----------|--------------|
| 安装 exe → 加载动画 → 「点击进入」→ 登录 → 工作台首页 完整启动链 | 短视频剪辑 Module（React timeline + dsh-tool-ffmpeg）整体 → V2 |
| 顶栏双模式：工作台面板模式 / 智能工作台模式 | 智能工作台模式全业务闭环真实跑通（V1 只要骨架可点、跳转正确） |
| 12 业务页 + 设置页全部迁移为官方 Module（shadcn/ui 重组） | OTA 签名上架的运营流程（catalog 接口与本地 zip 优先） |
| 首页 AI 对话框 + 引导跳转 + 简报卡片 | 服务端模型中转、SSE（后端 V1 既定边界） |
| 设置页：账号信息、偏好、**Skill 管理面板**（列出/启停/详情） | 第三方 Module 开发者生态（module-starter 模板与 SDK 文档放 P4） |
| Bridge：auth / 积分余额 / agent.run / nav.go；扣费链路（余额检查 → lease → usage 上报） | 剪辑类 `media:*` permission 与 ffmpeg 工具链（❌ 待讨论） |

**UI 组件规范**：所有页面用 `不加班智能团后端/.worktrees/v1-backend/web/admin` 的 shadcn/ui 组件体系重组（Tailwind v4 + Base UI 版 shadcn，`PageShell` / `data-table` / `dialog` / `sonner` 等，组件目录 `src/components/ui/`，约 39 个）。React 锁 18.3。交付包仅取**页面业务逻辑、交互流与路由值**，旧组件弃用。

**页面清单（12 页）**：以交付包 `README_KINCHENG.md` §1 与 `FRONTEND_ROUTE_MAP.md` 为验收依据——首页 `#overview`、热点雷达、爆款分析、选题池/排期 `#topic-pool`、内容创作、爆款复刻、内容资产库、内容数据复盘、朋友圈运营、产品库、AI 专家团、企业大脑、设置 `#settings`。
