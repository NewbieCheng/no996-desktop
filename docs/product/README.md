## 文档定位与状态标注约定

本目录文档为**目标设计**(architecture as spec):描述要构建的系统,而非已上线现状。文中「待实现」「待增」标记表示依赖项尚未存在。请勿按「已交付系统参考手册」阅读。各阶段实施顺序见文档 01 §8 路线图。

## 已确认的产品决策

- **V1 不做短视频剪辑**：剪辑 Module、timeline 组件、ffmpeg 工具链（`no996-tool-ffmpeg`、`media:*` permission）❌ 划掉，标 **待讨论**——是否做、何时做均未定，不在任何版本默认排期
- **启动链**：安装 exe → 加载动画（模块/预加载进度）→ 「点击进入」→ 登录页 → 工作台首页（默认面板模式）
- **顶栏双模式**：工作台面板模式（左侧 Sidebar + 业务页，即交付包形态）/ 智能工作台模式（按功能模块逐页执行 AI 操作的面板视角）；V1 智能工作台模式只需架构与骨架可点，不要求业务闭环全部跑通，扣费界面先做展示位
- **首页形态**：AI 聊天框（「今天该干什么」+ 引导跳转左侧功能页）+ 经营简报卡片区
- **设置页**：从占位页升级为账号信息 + 偏好 + Skill 管理面板（列出/启用/停用/详情）
- Agent 面板:**独立窗口**
- Module 分发:**本地安装 + 服务端 OTA**
- 外部页面集成:**React 深度集成**(非 iframe 为主路径)
- **UI 组件统一复用后端管理后台(web/admin)的 shadcn/ui 组件体系**(Tailwind v4 + Base UI 版 shadcn,TanStack Table / Recharts / sonner);交付包旧组件弃用
- React 锁定 18.3(对齐 web/admin),不用交付包的 React 19
- 桌面端实现落点为独立工作区 `no996-desktop`;其 `AGENTS.md` 与 `docs/PROGRESS.md`(进度唯一权威)、`docs/MIGRATION.md`(逐页迁移清单)由开发会话维护
